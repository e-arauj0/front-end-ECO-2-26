Glossário de Tecnologias da Web

HTML
Linguagem de marcação utilizada para estruturar o conteúdo de páginas Web, como textos, imagens, links e títulos.

CSS
Linguagem usada para definir a aparência e o estilo de páginas HTML, incluindo cores, fontes, espaçamentos e layouts.

JavaScript
Linguagem de programação utilizada para adicionar interatividade e comportamentos dinâmicos às páginas Web.

HTTP
Protocolo utilizado para a comunicação entre navegadores e servidores na Web, permitindo a transferência de recursos.

SQL
Linguagem utilizada para consultar, inserir, alterar e organizar dados armazenados em bancos de dados relacionais.
