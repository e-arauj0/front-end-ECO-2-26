Passos para criar uma página

  1. Crie uma pasta para o projeto:
    Escolha um local no computador e crie uma pasta, por exemplo, meu-site.

  2. Crie o arquivo HTML
    Dentro da pasta, crie um arquivo chamado index.html.

  3. Adicione a estrutura básica do HTML
    Use a tag !DOCTYPE html e as tags principais: html, head e body.

  4. Defina o título da página
    Dentro da tag head, adicione a tag title para definir o título que aparecerá na aba do navegador.

  5. Adicione o conteúdo
    Dentro de da tag body, coloque textos, títulos, imagens, links, listas e outros elementos que deseja exibir.

  6. Salve o arquivo
    Verifique se o arquivo foi salvo com a extensão .html.

  7. Abra a página no navegador
    Clique duas vezes em index.html ou abra-o usando um navegador como Chrome, Firefox ou Edge.

  8. Faça alterações e teste
    Edite o código, salve novamente e atualize a página no navegador para visualizar as mudanças.
