Nome do projeto: IFSP - Connect

Autor: Emily Oliveira Araujo

Curso: Engenharia de computação

Objetivo do projeto: 

    O objetivo do IFSP Connect é aplicar, na prática, os conhecimentos de Desenvolvimento Front-End, criando um website completo e funcional. O projeto permite desenvolver habilidades em HTML, CSS e JavaScript, incluindo responsividade e interatividade. Ao final, o site servirá como um portfólio dos conhecimentos adquiridos durante a disciplina.

Tecnologias utilizadas:
    HTML;
    CSS;
    JavaScript.
